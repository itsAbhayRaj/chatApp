# 💬 Real-Time Chat Web Application

A full-stack real-time chat application built with the MERN stack (MongoDB, Express, React, Node.js), powered by **Socket.IO** for live messaging and **JWT** for secure user authentication. Styled with **Tailwind CSS** and **CSS3**, and using **Redux** for efficient state management.

## 🚀 Features

- 🧑‍💻 **User Authentication** (JWT-based)
- 📡 **Real-time Messaging** using Socket.IO
- 📨 One-to-One Chat Functionality
- 👥 User Presence (Online/Offline Status)
- 🧭 Global State Management with Redux
- 💅 Responsive UI with Tailwind CSS and CSS3
- 🔐 Protected Routes
- 🗑️ Message Deletion / Cleanup (optional feature)

## 🛠️ Tech Stack

- **Frontend**: React.js, Redux, Tailwind CSS, HTML5, CSS3
- **Backend**: Node.js, Express.js, MongoDB
- **Real-Time**: Socket.IO
- **Auth**: JWT (JSON Web Tokens)
